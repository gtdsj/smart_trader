# 飞书机器人快速启动指南

## 概述

本指南将帮助您快速配置和启动智能量化交易系统的飞书机器人功能。飞书机器人可以让您通过聊天界面查询策略信息、筛选股票等。

## 前置条件

1. **飞书开放平台账号**：需要有飞书开放平台的开发者账号
2. **Python环境**：确保已安装Python 3.13和相关依赖
3. **系统配置**：智能量化交易系统已正确配置

## 步骤1：创建飞书应用

### 1.1 登录飞书开放平台

访问 [飞书开放平台](https://open.feishu.cn/) 并登录您的账号。

### 1.2 创建企业自建应用

1. 点击「创建应用」
2. 选择「企业自建应用」
3. 填写应用信息：
   - **应用名称**：智能量化交易助手
   - **应用描述**：提供量化交易策略查询和股票筛选功能
   - **应用图标**：上传合适的图标

### 1.3 配置应用权限

在应用管理页面，配置以下权限：

**机器人权限**：
- `im:message` - 获取与发送单聊、群组消息
- `im:message.group_at_msg` - 接收群聊中@机器人消息事件
- `im:message.group_at_msg:readonly` - 获取群组中所有消息
- `im:message.p2p_msg` - 接收用户单聊消息事件
- `im:message.p2p_msg:readonly` - 获取用户发给机器人的单聊消息

**事件权限**：
- `im.message.receive_v1` - 接收消息事件

### 1.4 获取应用凭证

在「凭证与基础信息」页面获取：
- **App ID**
- **App Secret**
- **Verification Token**
- **Encrypt Key**

## 步骤2：配置系统

### 2.1 修改配置文件

编辑 `config.json` 文件，添加飞书配置：

```json
{
  "feishu": {
    "enabled": true,
    "app_id": "your_app_id_here",
    "app_secret": "your_app_secret_here",
    "verification_token": "your_verification_token_here",
    "encrypt_key": "your_encrypt_key_here"
  }
}
```

### 2.2 安装依赖

确保已安装飞书SDK：

```bash
pip install lark-oapi
```

## 步骤3：测试配置

### 3.1 运行集成测试

```bash
python test/test_feishu_integration.py
```

### 3.2 运行自动化测试

```bash
python test/test_feishu_bot_auto.py
```

如果测试通过，说明配置正确。

## 步骤4：启动系统

### 4.1 启动主系统

```bash
python main.py
```

系统启动后，您应该看到类似以下的日志：

```
飞书机器人服务依赖初始化完成
飞书客户端初始化完成
飞书机器人服务初始化完成
飞书机器人已启动
```

### 4.2 验证机器人状态

在飞书中搜索您的机器人名称，添加机器人到聊天。

## 步骤5：使用机器人

### 5.1 基本指令

向机器人发送以下指令：

- **`帮助`** - 显示帮助信息
- **`获取可用策略列表`** - 查看所有可用的交易策略
- **`根据id为1的策略筛选股票`** - 使用指定策略筛选股票
- **`获取策略1详情`** - 查看策略的详细信息

### 5.2 示例对话

```
用户: 帮助
机器人: 🤖 智能量化交易助手

📚 可用功能:
1️⃣ 策略管理
• 获取可用策略列表
• 获取策略1详情

• 根据id为1的策略筛选股票
• 根据策略'策略名称'筛选股票

3. 动量策略

💡 使用提示:
• 发送 '根据id为1的策略筛选股票' 来使用策略筛选
• 发送 '获取策略1详情' 来查看策略详情
```

## 故障排除

### 常见问题

1. **机器人无响应**
   - 检查网络连接
   - 验证飞书应用配置
   - 查看系统日志

2. **权限错误**
   - 确认应用权限配置正确
   - 检查机器人是否已添加到聊天

3. **配置错误**
   - 验证 `config.json` 中的飞书配置
   - 确保所有必要字段都已填写

### 日志查看

系统日志位于 `logs/` 目录下，查看相关日志文件：

```bash
# 查看最新日志
tail -f logs/smart_trader_YYYYMMDD.log

# 搜索飞书相关日志
grep -i "feishu" logs/smart_trader_*.log
```

## 安全注意事项

1. **保护应用凭证**：不要将App Secret等敏感信息提交到版本控制系统
2. **权限最小化**：只申请必要的权限
3. **消息验证**：系统会验证消息来源的合法性
4. **访问控制**：考虑限制机器人的使用范围

## 扩展功能

您可以在 `services/feishu_bot_service.py` 中添加新的指令处理逻辑：

```python
# 在 _process_message 方法中添加新的指令匹配
if "自定义指令" in message:
    return await self._handle_custom_command(message)
```
