# 股票基本信息更新API接口文档

## 概述

本文档详细记录了新增的股票基本信息更新API接口，该接口用于手动触发全A股股票基本信息的更新，以及查询更新状态。

## API接口列表

### 1. 更新股票基本信息

**接口地址**: `POST /api/v1/data/update-stock-info`

**功能描述**: 手动触发全A股股票基本信息更新到数据库

**请求参数**: 无

**响应格式**:

**成功响应**:
```json
{
    "success": true,
    "message": "股票基本信息更新成功",
    "data": {
        "total_count": 5000,
        "success_count": 4950,
        "failed_count": 50,
        "duration": "120.50秒",
        "update_time": "2025-07-13T17:05:58.123456"
    },
    "timestamp": "2025-07-13T17:05:58.123456"
}
```

**失败响应**:
```json
{
    "success": false,
    "message": "股票基本信息更新失败: 无法连接到数据源",
    "data": {
        "success": false,
        "message": "无法连接到数据源"
    },
    "timestamp": "2025-07-13T17:05:58.123456"
}
```

**错误响应**:
```json
{
    "detail": "更新股票基本信息时发生错误: 具体错误信息"
}
```

### 2. 获取股票信息更新状态

**接口地址**: `GET /api/v1/data/stock-info-status`

**功能描述**: 获取股票基本信息更新状态和调度器状态

**请求参数**: 无

**响应格式**:

**成功响应**:
```json
{
    "success": true,
    "message": "获取股票信息更新状态成功",
    "data": {
        "scheduler_status": {
            "is_running": true,
            "description": "每日自动更新调度器运行中"
        },
        "update_status": {
            "updated_today": false,
            "last_check_time": "2025-07-13T17:05:58.123456",
            "description": "今日未更新"
        },
        "next_update": {
            "scheduled_time": "每日09:00",
            "condition": "交易日自动执行"
        }
    },
    "timestamp": "2025-07-13T17:05:58.123456"
}
```

## 实现位置

- **API文件**: `api/business/data.py`
- **服务类**: `services/stock_info_updater.py` - `StockInfoUpdater`
- **路由注册**: `main.py` - 通过 `api/routes.py` 注册

## 核心功能

### 1. 股票信息更新流程

1. **获取股票列表**: 调用 `_get_all_a_share_stocks()` 获取全A股列表
2. **批量更新**: 使用 `XtQuantService.batch_update_stock_basic_info()` 批量更新
3. **结果统计**: 统计成功、失败数量和耗时
4. **缓存刷新**: 更新完成后刷新股票信息缓存
5. **日志记录**: 记录详细的更新日志

### 2. 状态检查功能

1. **今日更新检查**: 检查当日是否已执行过更新
2. **调度器状态**: 获取每日自动更新调度器的运行状态
3. **下次更新时间**: 显示下次自动更新的计划时间

## 依赖服务

1. **StockInfoUpdater**: 股票信息更新器（单例模式）
2. **XtQuantService**: XtQuant数据服务
3. **StockInfoCacheService**: 股票信息缓存服务
4. **数据库**: 存储股票基本信息

## 使用示例

### Python 请求示例

```python
import requests

# 更新股票基本信息
response = requests.post("http://localhost:8000/api/v1/data/update-stock-info")
result = response.json()
print(f"更新结果: {result}")

# 获取更新状态
response = requests.get("http://localhost:8000/api/v1/data/stock-info-status")
status = response.json()
print(f"更新状态: {status}")
```

### curl 请求示例

```bash
# 更新股票基本信息
curl -X POST "http://localhost:8000/api/v1/data/update-stock-info"

# 获取更新状态
curl -X GET "http://localhost:8000/api/v1/data/stock-info-status"
```

## 错误处理

### 常见错误类型

1. **数据源连接失败**: XtQuant服务未连接或网络问题
2. **数据库错误**: 数据库连接失败或写入错误
3. **权限错误**: 缺少数据访问权限
4. **超时错误**: 更新过程超时

### 错误处理机制

- **异常捕获**: 完整的异常捕获和堆栈信息记录
- **错误日志**: 详细的错误日志记录
- **状态返回**: 明确的成功/失败状态返回
- **错误信息**: 用户友好的错误信息提示

## 性能考虑

### 更新性能

- **批量处理**: 使用批量更新减少数据库操作
- **异步执行**: 异步处理提高响应速度
- **缓存更新**: 更新完成后及时刷新缓存

### 并发控制

- **单例模式**: StockInfoUpdater使用单例模式避免重复实例
- **状态检查**: 避免重复更新同一天的数据
- **调度器集成**: 与每日自动调度器协调工作
