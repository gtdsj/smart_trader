# 飞书机器人配置指南

本文档介绍如何在智能量化交易系统中配置和使用飞书机器人。

## 功能概述

飞书机器人集成到量化交易系统中，提供以下功能：

1. **获取可用策略列表** - 查看系统中所有可用的交易策略
2. **根据策略筛选股票** - 使用指定策略筛选符合条件的股票
3. **获取策略详情** - 查看特定策略的详细信息
4. **帮助信息** - 获取机器人使用说明

## 配置步骤

### 1. 创建飞书应用

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 获取 `App ID` 和 `App Secret`
4. 配置应用权限：
   - `im:message` - 接收和发送消息
   - `im:message.group_at_msg` - 群聊@消息
   - `im:message.p2p_msg` - 私聊消息

### 2. 配置系统环境变量

在系统环境变量或 `.env` 文件中添加以下配置：

```bash
# 飞书机器人配置
FEISHU_APP_ID=your_app_id_here
FEISHU_APP_SECRET=your_app_secret_here
FEISHU_ENABLED=true
```

### 3. 配置文件设置

在 `config.json` 文件中添加飞书配置：

```json
{
  "feishu": {
    "app_id": "your_app_id_here",
    "app_secret": "your_app_secret_here",
    "enabled": true
  }
}
```

### 4. 启动系统

配置完成后，启动量化交易系统：

```bash
python main.py
```

系统启动时会自动初始化飞书机器人服务。

## 技术实现

### 架构设计

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   飞书客户端    │───▶│  飞书机器人服务  │───▶│   策略服务      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                              │
                              ▼
                       ┌─────────────────┐
                       │  股票筛选服务    │
                       └─────────────────┘
```

### 核心组件

1. **FeishuBotService** - 飞书机器人服务主类
2. **消息处理器** - 解析和处理用户消息
3. **响应生成器** - 生成格式化的响应消息
4. **服务集成** - 与策略服务和股票筛选服务集成

### 依赖库

- `lark_oapi` - 飞书开放平台SDK
- `asyncio` - 异步编程支持
- `re` - 正则表达式匹配
- `json` - JSON数据处理

## 故障排除

### 常见问题

#### 1. 机器人无响应

**可能原因：**
- App ID 或 App Secret 配置错误
- 应用权限配置不正确
- 网络连接问题

**解决方法：**
- 检查配置文件中的 App ID 和 App Secret
- 确认飞书应用权限配置
- 检查网络连接和防火墙设置

#### 2. 策略列表为空

**可能原因：**
- 策略服务未正确初始化
- 策略配置文件缺失

**解决方法：**
- 检查策略服务启动日志
- 确认策略配置文件存在且格式正确

#### 3. 股票筛选失败

**可能原因：**
- 数据服务连接失败
- 策略参数配置错误
- 市场数据缺失

**解决方法：**
- 检查数据服务连接状态
- 验证策略参数配置
- 确认市场数据源可用

```bash
# 查看飞书机器人相关日志

```

## 安全注意事项

1. **保护敏感信息**
   - 不要在代码中硬编码 App ID 和 App Secret
   - 使用环境变量或安全的配置管理

2. **权限控制**
   - 仅授予必要的应用权限
   - 定期检查和更新权限配置

3. **消息验证**
   - 验证消息来源的合法性
   - 对用户输入进行适当的验证和过滤

4. **错误处理**
   - 不要在错误消息中泄露敏感信息
   - 记录详细的错误日志用于调试
