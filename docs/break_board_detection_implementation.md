# 破板检测功能实现文档

## 概述

本文档详细记录了在量化交易系统中实现的破板检测功能，该功能用于识别股票在触及涨停价后回落的情况。

## 功能描述

破板检测功能主要判断股票是否满足以下条件：
1. 当天最高价等于计算出的涨停价
2. 收盘价低于涨停价
3. 根据股票类型正确计算涨停价（考虑不同的涨跌幅限制）

## 实现位置

- **文件**: `services/custom_condition_manager.py`
- **类**: `IsBreakBoardCondition`
- **方法**: `calculate()`, `_calculate_limit_up_price()`, `_get_limit_ratio()`

### 2. 涨停价格计算 (`_calculate_limit_up_price`)

根据前一交易日收盘价和涨跌幅限制计算涨停价：
- 获取股票基础信息（用于判断是否为ST股）
- 根据股票类型获取涨跌幅限制比例
- 计算涨停价并四舍五入到分

### 3. 涨跌幅限制获取 (`_get_limit_ratio`)

根据股票代码和基础信息确定涨跌幅限制：
- **ST股票**: 5%
- **创业板** (300开头): 20%
- **科创板** (688开头): 20%
- **北交所** (8开头, 43开头): 30%
- **主板**: 10%

## 股票类型识别规则

| 股票类型 | 代码规则 | 涨跌幅限制 |
|---------|---------|----------|
| ST股票 | 通过数据库is_st字段判断 | 5% |
| 创业板 | 300开头 | 20% |
| 科创板 | 688开头 | 20% |
| 北交所 | 8开头或43开头 | 30% |
| 主板 | 其他A股 | 10% |

## 破板判断条件

股票被认定为破板需要同时满足：
1. `最高价 == 涨停价` （触及涨停）
2. `收盘价 < 涨停价` （未能封住涨停）

## 依赖服务

1. **StockInfoCacheService**: 获取股票基础信息（是否ST股等）
2. **数据库**: 存储股票基础信息
3. **股票数据**: 包含开高低收价格和成交量的DataFrame

## 错误处理

- 数据不足时返回0（未破板）
- 无法获取股票信息时使用默认涨跌幅限制（10%）
- 计算异常时记录错误日志并返回0

## 性能考虑

- 使用缓存服务减少数据库查询
- 简单的数值计算，性能开销较小
- 支持批量处理多只股票

## 注意事项

1. **数据质量**: 确保股票数据的准确性和完整性
2. **时间同步**: 确保前一交易日和当前交易日数据的时间对应关系
3. **停牌处理**: 停牌股票可能没有价格数据，需要适当处理
4. **新股处理**: 新上市股票可能有特殊的涨跌幅规则
