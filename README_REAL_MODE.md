# 量化交易系统 - 真实模式运行指南

## 概述

本系统已配置为真实模式，可以连接到实际的xtquant服务和DuckDB数据库进行量化交易。

## 系统要求

### 软件依赖
- Python 3.13+
- QMT客户端（迅投极速交易终端）
- 所有Python依赖包（见requirements.txt）

### 硬件要求
- 稳定的网络连接
- 足够的磁盘空间存储历史数据

## 配置说明

### 主要配置文件：`config.json`

```json
{
  "system": {
    "simulation_mode": false,  // 必须为false以启用真实模式
    "debug": true
  },
  "database": {
    "memory": false,           // 使用文件数据库
    "path": "data/smart_trader.db"  // DuckDB数据库文件路径
  },
  "xtquant": {
    "path": "D:\\江海证券QMT实盘_交易\\userdata_mini",  // QMT安装路径
    "session_id": 123456,
    "account_id": "85110106",   // 您的交易账户ID
    "account_type": "STOCK"
  }
}
```

### 重要配置项说明

1. **xtquant.path**: QMT客户端的userdata_mini目录路径
2. **xtquant.account_id**: 您的实际交易账户ID
3. **database.path**: DuckDB数据库文件存储路径

## 启动步骤

### 1. 环境准备

```bash
# 安装依赖
pip install -r requirements.txt

# 确保QMT客户端已安装并配置
```

### 2. 系统检查

运行系统检查脚本：

```bash
python test_real_mode.py
```

该脚本会检查：
- ✅ 配置文件是否正确
- ✅ DuckDB数据库连接
- ✅ XtQuant数据服务连接
- ⚠️ XtQuant交易服务连接（需要QMT客户端运行）

### 3. 启动系统

#### 方式一：使用启动脚本（推荐）

```bash
python start_real_mode.py
```

#### 方式二：直接启动FastAPI

```bash
python main.py
```

### 4. 访问Web界面

系统启动后，访问：
- 主页面：http://localhost:8000
- API文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

## 注意事项

### 交易相关
1. **QMT客户端必须运行**: 交易功能需要QMT客户端在后台运行并已登录
2. **账户权限**: 确保账户有相应的交易权限
3. **资金安全**: 建议先在模拟环境测试策略
4. **风险控制**: 系统内置风险控制，但请谨慎设置参数

1. **日志监控**: 关注系统日志，及时发现问题

## 故障排除

### 常见问题

#### 1. 数据库连接失败
```
错误: 数据库初始化失败
解决: 检查DuckDB依赖是否正确安装，确保数据目录有写权限
```

#### 2. XtQuant数据服务连接失败
```
错误: xtdata模块未安装或连接失败
解决: 确保xtdata包已正确安装，检查网络连接
```

#### 3. 交易服务连接失败（错误码-1）
```
错误: 连接交易服务器失败，错误码: -1
解决: 
1. 确保QMT客户端已启动并登录
2. 检查xtquant.path配置是否正确
3. 确认账户ID和类型配置正确
```

#### 4. 配置文件问题
```
错误: 配置加载失败
解决: 检查config.json格式是否正确，路径是否存在
```
